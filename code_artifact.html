故事背景：摸魚研究員的秘密

作為星炬學院虛質科學部著名的「優等摸魚生」，達妮婭永遠能找到最舒適的角落打瞌睡。無論是學科討論會還是嚴肅的理論研討，她總是用那招牌式的「溫柔微笑」應對一切，隨後默默戴上眼罩補眠。

然而，當虛質危機爆發或戰場需要諧律介入時，達妮婭手中的音感儀能精準操控「虛粒」與「暗核」，將暴力的熱熔能量轉化為如歌劇般精密的粒子演出。好友西格莉卡常常對她又無奈又佩服。

「再優秀的共鳴演算，如果不能換來三小時安穩的午睡，那也太不划算了吧？」

KIT & RESONANCE MODES

雙模態機制與技能解析

演劇形態 (Stagecraft Form)

聚怪與資源蓄積階段
【虛粒 (Void Particle)】

上限 100 點。演劇形態下普攻與變奏技能命中即可獲取，滿額時可觸發強效聚怪力場。

【暗核 (Dark Core)】

最多儲存 3 個。每12秒或施放登場技能時生成1個，持續吸引周圍目標並進行熱熔微頻共振。

瓦解形態 (Breakdown Form)

爆發與同型電荷階段
【同型電荷 (Conformal Charge)】

上限 100 點。瓦解形態下普攻與技能「驅逐」獲得，消耗電荷可釋放高額熱熔無視防禦傷害。

【暗核引爆 (Core Collapse)】

消耗暗核直接將場上力場轉化為瞬發熱熔核爆，大幅提升共鳴解放【終幕】的傷害倍率。

RESONANCE CHAINS

共鳴鏈 ( S1 ~ S6 ) 突破提升

S1. 昏暗夢境中的微光 抗打擾/暴傷

暴擊傷害提升30%。施放技能與普攻段數時獲得霸體抗打斷效果；進入戰場時自動獲取「熵移」效果。

S2. 現實浪潮中的沉浮 關鍵爆發鏈

隊友引發熱熔聚爆後，全隊獲得50%熱熔傷害加成。達妮婭疊加「退化虛質」，每層無視1%熱熔抗性；驅逐技能傷害提升40%。

S3. 虛質的繁複計算 數值提升

共鳴技能與共鳴解放傷害倍率提升。

S4. 學院特許的特權 協奏輔助

共鳴解放【終幕】段數增加，退場時使登場角色獲得額外熱熔傷害加成。

S5. 預演中的即興劇 技能等級

常規攻擊與變奏技能等級+2。

S6. 終幕的無聲宣告 質變滿鏈

瓦解形態下所有熱熔攻擊無視目標 30% 防禦力，施放必殺技後刷新共鳴技能CD，實現無縫連招爆發。
